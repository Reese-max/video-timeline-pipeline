## 1. Whisper 在第二段開頭漏轉約 30 秒

- **現象：** `analysis.transcript.segments` 在 `117.9–120.0`「会自动归类到费用这个页面里面去」之後，下一筆直接跳到 `149.6`「就像这个工作台」。120.0–149.6 秒之間沒有任何語音紀錄。
- **證據：** 這段時間畫面上一直有燒進去的字幕，代表講者有在講話。

| 原片時間 | 畫面字幕 |
|---|---|
| 2:00 | 而且还能看到逐年的趋势 |
| 2:04 | 所有上传的资料都能在这里找到 |
| 2:08 | 可以为自己或者家人建立独立的档案 |
| 2:12 | 就能得到一个完全空白的档案 |
| 2:16 | 做这个系统的时候 |
| 2:20 | 当真到陪他们去看病的时候 |
| 2:24 | 我们不一定能说清楚 |
| 2:28 | 最后能变成生活里用得上的东西 |

- **影響：** ChatGPT 摘要把這段誤判成「旁白較少」，還漏掉了「陪爸媽看病說不清病史」這段開發初衷的前半。
- **原因（main 程式註解的結論）：** 切段邊界剛好在 120 秒（`segment_seconds=120`）；硬切點撞上半句話時，Whisper 解碼器整個 30 秒視窗交白卷，屬模型側行為，放寬 `no_speech_prob` 過濾救不回來（還會召回幻覺）。main 的處置是合併後偵測 >5 秒的內部斷層，帶前後 15 秒上下文補轉。
- **驗收：** 0–166 秒之間，逐字稿不能有超過 5 秒的空白（片頭片尾除外）。上表的字幕內容要出現在逐字稿裡。
- **main 現況：** 驗收門檻即 `TRANSCRIPT_MAX_GAP = 5.0`，狀態看 `transcript.gap_check.remaining`（空陣列＝無斷層）；補轉失敗會讓品質判定改為 needs_review，殘留斷層則只列為提醒（warnings）。尚未用真實影片驗證。

## 2. MiniMax 畫面證據的時間碼壓縮了

- **現象：** 17 筆 `type=visual` 的時間全部落在 0.0–6.9，但影片長 166.6 秒。
- **對照表**（以語音和截圖推算實際時間）：

| 標記的 timestamp | 畫面內容 | 實際約在 |
|---|---|---|
| 0.3 | CareArk 網頁、GitHub 開源 | ~8s |
| 0.9 | 護理師抽血片段 | ~28s |
| 2.4 | 講者：「下面手把手演示」 | ~56s |
| 3.1 | `.env`／DeepSeek 設定 | ~65s |
| 4.9 | AI 辨識檢驗單 | ~104s |
| 6.2 | 原始資料頁、家人檔案 | ~124s |
| 6.9 | 講者結尾 | ~137s |

- **比例：** 大約 20～30 倍，而且不是固定值。看起來是單位或換算錯了，不是單純乘一個係數就能修。
- **影響：** 這次分段主要靠語音時間碼，所以影響不大。但小工具說「時間碼使用原片時間」，畫面證據的時間其實是錯的，沒辦法拿來對時間點。
- **驗收：** 畫面證據的 timestamp 要分布在 0–166 秒，和截圖對照的誤差不超過 5 秒。
- **main 現況：** 提示詞要求原片秒數並覆蓋全片；峰值不足時沿用已上傳檔案重問一次，仍不足就標未完成、不寫快取；逐筆 `timestamp_reliable`：超出片長或 ≥80% 擠在前 10% 的事件標為不可靠，widget 顯示「（時間碼不可靠）」且不給跳轉；不做 rescale。尚未驗證：與截圖誤差 ≤5 秒。

**2026-10-20 本機回歸修補（#56）：** 補問畫面空檔的回應先過濾空檔外與重複事件，再逐次檢查時間碼，避免首輪或被丟棄的事件掩蓋補問回應中集中在 1–6 秒的時間碼。完全位於片頭 10% 內的空檔，其事件不參與集中度檢查，避免把正常的片頭補問誤標為壓縮。修補保留原始時間與不可靠標記，不做比例換算；單支影片快取與 CLI `visual.json` 的驗證版本同步失效，MCP 快取沿用既有程式雜湊失效機制。

| 驗收項目 | 本次證據 | 結果 |
|---|---|---|
| 畫面時間碼使用原片秒數，異常分布不作可靠跳轉 | 首輪與補問分別檢查；補問只計保留事件，片頭空檔豁免集中度規則，壓縮補問事件保留原值並標不可靠 | 離線回歸測試見下列命令 |
| 不沿用未檢查補問時間碼的快取 | 舊 MP4 快取版本與 CLI 設定被拒，新快取保留不可靠標記且可重用 | 離線回歸通過 |
| 原始 166.6 秒影片、真實 MiniMax 回應與逐筆截圖誤差 ≤5 秒 | 本次未執行真實模型／媒體驗收，離線 provider 回應不能證明對齊 | **未驗證，#56 仍待驗收** |
