## 三、實際使用順序

1. 先用 React Bits、Uiverse 或 Aceternity UI 找到可用的視覺元件與版型方向。
2. 用 shadcn/ui 建立可修改、可維護的介面元件。
3. 最後用 anime.js 補上頁面轉場、互動與微動畫。

這個順序的核心是：先解決「看起來像什麼」，再處理「怎麼組成元件」，最後處理「怎麼動」。

## 四、查證與限制

- 影片畫面與語音一致指向上述五個網站；官方頁面也確認了名稱與主要定位。
- 影片提到的「165 個以上」與「7,400 個以上」是影片當時的數量描述；網站內容會持續變動，不應視為永久固定數字。
- 「免費」、「不需要註冊即可先瀏覽」是講者的說法；實際使用時仍要逐項確認授權、商用限制、署名要求，以及 Pro／付費內容。
- 元件可以複製，不代表可以忽略無障礙、效能、響應式與維護成本；AI 生成程式碼仍需測試與人工審查。
